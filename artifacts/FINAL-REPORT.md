# 知行最终报告

三个阶段都已做完，并在本机浏览器里逐项点过。开发服务现在开在 [知行](http://127.0.0.1:38471)。

本报告路径：`artifacts/FINAL-REPORT.md`。交付压缩包：`artifacts/zhixing-deliver.zip`。打包时排除了 `node_modules`、`.next`、`release` 构建产物、`uploads` 和 `.git`。

## 做了什么

### 阶段 1：导师、关系图谱、快速打开

- 侧栏可以进入关系图谱 `/study/graph`。有论文时画出节点和边，可以拖拽、缩放；点节点能看详情并打开论文页。没有论文时是空状态。
- 全局快速打开：Ctrl/Cmd+P，搜索文件库和论文，方向键、Enter、Esc 都可用，注册在应用外壳上，不占用导图快捷键。
- AI 导师引用文库论文，回答里带标题并可跳到论文页。没有中转站密钥时显示中文错误，页面不白屏。

### 阶段 2：Electron 桌面外壳

- `electron/main.cjs` 在需要时拉起 Next，就绪后开窗；关掉窗口会结束知行自己启动的进程树。
- 图标在 `build/icon.ico` 和 `build/icon.png`。`pnpm pack:win` 走 Next standalone，再用 electron-builder 打 NSIS 安装包和免安装版。
- `Start-Zhixing.bat` 仍可双击启动。数据目录仍是用户目录下的 `Zhixing`（可用 `ZHIXING_HOME` 改），升级不另起一份数据。
- 说明写在《Windows 打包与启动说明.md》。

### 阶段 3：工作台与全流程

- 工作台流程写成五步：主管拆解、成员执行、主管验收、汇总方案、交给执行器。执行器只有 WorkBuddy 和 DeepSeek Harness。
- 任务完成后可以选择执行器，确认命令再运行；本机没有装对应命令时会提示没找到，并可以取消。
- 思维导图补了 OPML 导出（和已有的 XMind、Markdown、图片导出放在一起）。打开导图时选中中心主题，工具栏的「子主题」等操作能直接用。
- 文件树可以拖拽移动笔记和文件夹。正在打开的文件被移走后，标签和地址栏会改到新路径，避免继续请求旧地址。

## 修过的问题

- 拖动文件后，标签历史改了，地址栏仍停在旧路径，页面继续读取已不存在的文件并出现 404。现在会改地址；如果当时已经有一次打开旧路径的导航在路上，也会改到新路径。
- 设置页的开关会触发「Maximum update depth exceeded」。Primer 的 ToggleSwitch 在回调函数每次新建时都会再调一次 `onChange`，内联函数因此无限循环。模型和执行器的开关改为稳定回调。
- 导图刚打开时没有选中主题，工具栏插不进子主题。挂载后会选中中心主题。
- 导图菜单里原先不能导出 OPML。现已补上，备注写在 `_note` 上，导回时还能读到。
- 还没配置模型就点「开始」会请求接口并得到 400，浏览器把它记成一条失败请求。现在先在页面上用同一句中文说明，不再发这次请求。
- 拖拽结束后有的浏览器还会点一下该行，把刚移走的文件按旧路径打开。拖拽后的短时间内忽略这次打开。

## 需在 Windows 上验证

Linux 上不能把安装包当成已经打成。`pnpm pack:win` 在制作 NSIS 安装包时会调用 wine，本环境没有 wine，所以没有得到可用的 exe。请在 Windows 上按《Windows 打包与启动说明.md》里的清单看：

1. `pnpm pack:win` 能跑完，`release\` 里同时有安装包和免安装版。
2. 安装、卸载，桌面和开始菜单有「知行」快捷方式，图标不是默认白纸。
3. 打开窗口后标题是「知行」，能进学习区；关窗口后没有残留的 `Zhixing.exe` 或 node。
4. `scripts\windows-shortcut.ps1` 能为免安装版创建桌面快捷方式。
5. 设置里选择文件库文件夹时，能弹出系统选目录对话框。
6. 论文和笔记在 `%USERPROFILE%\Zhixing`。覆盖安装或换免安装版再打开，内容还在。
7. 双击 `Start-Zhixing.bat` 仍用浏览器打开，不依赖 Electron。
8. 没有 Node.js 时，安装包或免安装版仍能打开；bat 会提示安装 Node.js。

## 已知限制

- 执行器要在 Windows 上安装 WorkBuddy（`codebuddy`）或 DeepSeek Harness（`dsh`）之后才能真正跑命令。没装时只会提示找不到，不会假装已经执行。
- 关系图谱和导图里的论文原文依赖本机文件库里的 PDF。示例论文很小，只用来确认对照栏能打开。
- 工作台的模型调用走中转站。没有密钥时不能完成真实协作；本报告里的协作结果是用本地模拟接口验证流程，不是三家模型的真实回答。
- 桌面窗口的选目录、关窗杀进程和安装包图标，都要在 Windows 上最终确认。
